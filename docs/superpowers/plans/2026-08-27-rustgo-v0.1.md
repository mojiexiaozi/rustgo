# Rustgo V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `rustgos` and `rustgoc` as a secure, bounded-resource TCP/UDP relay for personal self-hosting on Linux and Windows.

**Architecture:** A modular Cargo workspace separates configuration, cryptographic identity, wire protocol, transport helpers, and the two executables. One authenticated TLS control connection owns each client's public listeners; TCP uses one authenticated data connection per accepted stream and UDP uses a bounded persistent datagram channel.

**Tech Stack:** Stable Rust, Tokio, rustls/tokio-rustls, Serde, TOML, postcard, Ed25519, clap, tracing, proptest, cargo-fuzz, and GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-27-rustgo-v0.1-design.md`

## Global Constraints

- V0.1 is relay-only; it must not implement NAT discovery, hole punching, P2P, QUIC, TUN networking, multi-tenancy, billing, or a web UI.
- The executables are named exactly `rustgos` and `rustgoc`.
- `rustgos` with no arguments is equivalent to `rustgos -c server.toml`; `rustgoc` with no arguments is equivalent to `rustgoc -c client.toml`.
- TOML is the only configuration format; unknown fields are errors and relative paths resolve from the configuration file directory.
- Production connections require TLS 1.3 plus Ed25519 challenge authentication bound to client name, session ID, and protocol version.
- Control traffic and application data use separate TLS connections.
- Every externally influenced frame, queue, connection set, tunnel set, authentication path, and UDP session table has a tested hard bound.
- Logs are human-readable single-line text only; JSON output is not implemented.
- Linux is the primary server platform; Windows and Linux clients must interoperate.
- Apply TDD for every behavioral change and make the commits listed below only after their scoped tests pass.
