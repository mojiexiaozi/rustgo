# 客户端编辑服务器同步配置

用户要求客户端也能修改，取代上一版只读约束。两端共享服务器持久化配置，客户端通过自身设备身份和 TLS 修改自身配置，不使用管理员密码。保存带预期修订号，冲突不得覆盖服务器新版本；草稿保留供用户调整或显式重新载入。断线不显示保存成功，旧服务端明确提示升级。

实施分工：
- 根任务：扩展版本协商和配置请求，增加带修订号的原子替换；客户端导出独立保存 API；真实握手测试验证保存、重连、冲突及旧版兼容。
- GUI 子任务：恢复全部类型的卡片编辑，独立草稿、异步保存和冲突提示，保留本地身份和 P2P 设置，测试草稿不被轮询覆盖。
- 集成：运行相关测试及审查，更新 Windows 客户端和服务器，备份后线上验证客户端保存与服务器视图一致。

执行记录：设计按用户明确要求采用两端可编辑；原有服务端管理和持久化继续使用。仅替换当前设备自己的三个配置集合，版本冲突要求重载，不自动强制覆盖。
