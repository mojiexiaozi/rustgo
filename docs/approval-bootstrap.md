# 客户端自动接入

客户端首次启动只需配置服务器地址和客户端名称。缺少本地证书时，首次申请通过 TLS 获取服务器证书，提交本机生成的公钥及签名；私钥不上传，也不由服务器下发。

首次连接采用首次使用信任（TOFU），尚不能通过预装证书验证服务器身份。申请记录立即保存观察到的服务器证书指纹，后续轮询固定验证该指纹。已有证书或已保存的指纹不会因连接失败而回退到首次接入模式。

管理员批准后，客户端保存接入身份和服务器证书指纹，启用本地密钥并连接。审批前不会启动业务转发。管理员应在服务器管理页核对申请的客户端公钥指纹。

- 新名称：显示“申请已提交，等待管理员审批”。
- 已存在的动态客户端名称：提交密钥更换申请，客户端明确提示批准后会替换原密钥；批准前原身份不变。
- 静态配置占用名称或密钥：明确提示冲突，不自动覆盖静态配置。
- 请求未到达服务器：显示连接重试状态，不显示已经等待审批。

不再要求裸 exe 携带 `server-cert.pem`，也不内置某台部署服务器的证书。运行目录仍用于保存客户端配置、候选密钥和审批状态。
