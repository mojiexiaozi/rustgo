# 客户端名称与 UID

新客户端的名称默认使用当前系统用户名，可使用中文，也可以与其他设备重名。名称仅用于显示；审批时服务器分配随机 UID，认证、删除和配置操作仍按设备身份区分。修改显示名称不会生成新设备，也不会改变已有隧道。

客户端配置页、概要和服务器客户端卡片显示名称、UID、本地 IP。本地 IP 是客户端连接服务器使用的网卡地址，重新连接时更新，不是服务器看到的公网地址。

已有动态客户端升级后沿用服务器原有内部 UID、密钥和隧道配置。原认证名称保留为兼容路由标识；显示名称独立保存。旧版静态客户端保留原有认证方式，页面标明尚未分配 UID。

审批请求签名覆盖显示名称和恢复目标 UID。同名新设备分别申请；恢复已有 UID 必须重新由管理员批准。旧审批请求可在升级后继续查询。

协议 1.5 同步显示资料；与旧版服务器连接时不发送新增资料字段。使用新式同名设备审批需要升级服务器。身份数据库自动从版本 4 迁移到版本 5；回退旧服务器程序时须同步恢复升级前的身份数据库备份。
